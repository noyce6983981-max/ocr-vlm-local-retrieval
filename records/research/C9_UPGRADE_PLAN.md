# 面向C9复试的项目升级方案

## 结论

当前24张数据和启发式质量门控是一个扎实原型，但单独作为C9层次的核心科研贡献不够。升级后的目标是形成一个可回答的研究问题：

> 在单张8GB消费级显卡上，面对OCR不可靠、版面复杂且格式异构的个人资料，如何兼顾检索准确率、延迟和可解释性？

## 拟定方法

暂定名称：UCG-Retrieve（Uncertainty-Calibrated Gated Retrieval）。

```text
PDF / DOCX / PPTX / 图片 / ZIP
  → 统一页面化与结构解析
  → OCR文本召回 + VLM视觉召回
  → 可学习的OCR不确定性门控
  → 合并Top-K候选
  → Qwen3-VL-Reranker-2B多模态重排
  → Top-K结果与分支解释
```

## 三个真正可讲的贡献

### 1. 200页多格式困难检索基准

- 不是随机图片堆积，而是包含PDF、Office、图片、复杂版面和无文字图片。
- 设计同主题、相邻页、相似版式等困难负样本。
- 按原始文档分组划分开发/验证/测试，避免页面泄漏。

### 2. 可学习的不确定性门控

从当前单一“平均OCR置信度”升级为轻量模型，输入候选特征：

- OCR均值、最小值和方差
- 文本框数量、字符数和页面文字覆盖率
- 清晰度、倾斜角和分辨率
- 文本分支与视觉分支分数差
- 查询类型和OCR文本长度

输出候选级文本权重。训练对象是轻量MLP或逻辑回归，不在200页上强行微调2B基础模型。

### 3. 多模态二阶段重排

- 第一阶段用BGE-M3和Qwen3-VL-Embedding快速召回。
- 第二阶段只对候选Top 10使用Qwen3-VL-Reranker-2B做跨模态精排。
- 比较准确率提升、平均延迟和显存峰值，形成效果—成本曲线。

## 必做对照与消融

1. OCR文本检索
2. 视觉Embedding检索
3. 固定50/50融合
4. 当前启发式置信度门控
5. 可学习门控
6. 可学习门控 + 多模态Reranker
7. 去掉版面/清晰度特征
8. 去掉困难负样本后的性能变化

指标：

- Recall@1、Recall@5、Recall@10、MRR、nDCG@10
- 文本依赖、视觉依赖、混合依赖三类分项指标
- 首次查询延迟、缓存延迟、单页入库耗时、显存峰值
- OCR退化程度分桶性能

## 前沿技术取舍

- 主线采用Qwen3-VL-Reranker-2B：与现有Qwen3-VL-Embedding同源，适合二阶段检索，2B规模有机会在8GB显卡顺序运行。
- PaddleOCR-VL-1.6作为复杂版面解析对照：只先测20至30页，不立刻替换全流程。
- ColPali/ColQwen多向量晚交互作为可选基线：科研价值高，但显存和索引体积更大，主线完成后再决定。
- 不使用世界模型：它与静态文档检索的问题结构不匹配，强行加入会削弱项目逻辑。

## 达到什么程度才“够看”

- 200页严格数据集和至少200条人工真值查询。
- 可学习门控在冻结测试集上优于启发式门控，具体提升待实验验证。
- Reranker的收益与延迟代价均有数据。
- 至少一组跨类别或跨质量泛化实验。
- 6至8页论文式技术报告、完整GitHub、3分钟演示和失败案例分析。

这仍不能保证C9录取，但会从“调用开源模型的Demo”提升为“有问题定义、方法和实验闭环的本科科研项目”。
