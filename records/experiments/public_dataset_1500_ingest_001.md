# 1500页公开资料库扩展与质量路由实验

日期：2026-07-29

## 目的

验证本地OCR-VLM系统能否在RTX 4060 Laptop GPU上处理千页级异构资料，并把来源、重复、隐私、OCR和类别风险转化为可人工裁决的质量队列。

## 数据

- 总页数：1500；页面ID唯一数：1500。
- 类别：清晰文档225、复杂学术225、表格票据225、PPT海报188、软件网页150、场景文字187、退化文档150、无文字自然图150。
- 新增1300页来源：RVL-CDIP、RICO-SCA、TextVQA、Caltech-101、FUNSD。
- 新增1300页声明AI生成占比：0%；早期200页未证明部分保持“不确定”，没有倒推。
- 新增1300页精确重复和感知近重复：0。

## 本机运行结果

| 阶段 | 耗时 |
|---|---:|
| 文档准备 | 2.577秒 |
| PP-OCRv5 | 762.661秒 |
| OCR语料 | 1.174秒 |
| BGE-M3文本索引 | 49.160秒 |
| Qwen3-VL视觉索引 | 260.163秒 |
| 总计 | 1099.387秒 |

本批准备1300页、新增1300页、重复0页，最终资料库1500页。文本索引和2048维视觉索引均覆盖1500页。

## 质量路由

| 路由 | 页数 |
|---|---:|
| 自动放行 | 1306 |
| 隐私复核 | 60 |
| 类别复核 | 5 |
| OCR低置信度 | 105 |
| 无文字类别出现文字 | 8 |
| OCR重试 | 16 |

合计194页需要人工审核。`natural_no_text`类别共有13个文字泄漏候选，其中部分是远处水印或背景小字，部分确实是类别错误；因此自动规则只负责路由，不能直接覆盖类别真值。

## 产品化改进

- 支持目录、ZIP、PDF、DOCX、PPTX和图片批量页面化。
- 每个资料库独立保存原图、OCR、文本索引、视觉索引和查询缓存。
- 导入任务写入阶段状态，结果页显示原文件、页码、公开来源与许可证。
- 新增网页质量中心，由本人选择接受、重分类、重做OCR或隔离，并原子保存带时间戳的审计记录。
- 审核决定采用草稿—发布两阶段；发布前自动备份manifest，隔离页退出实时检索，版本变化使旧缓存自动失效。
- 中文查询返回1500个候选；相同查询缓存响应约0.3秒，首次完整计算约33秒。

## 结论边界

- 本实验验证千页级工程链路和数据治理流程，不等同于1500页正式检索精度实验。
- 24页试运行集上的Recall和MRR不能外推；必须完成分组划分与查询真值审核后再报告正式结果。
- 当前是接近商业工作流的科研原型，尚不具备商业SaaS的多用户权限、并发、灾备和合规认证。
