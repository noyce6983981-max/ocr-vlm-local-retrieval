# 200页多格式个人资料测试集规范

目标不是堆200张互不相关的图片，而是构造能够检验OCR、视觉语义、版面理解和困难负样本的检索集。这里的“200”指转换后的200个检索单元：一张图片或文档的一页。

## 可直接复制的采集提示词

```text
请帮我整理一个用于“中文多格式个人资料多模态检索”的200页测试集。

要求：
1. 最终恰好200个检索单元，一张图片或PDF/Word/PPT的一页算一个单元。
2. 内容必须来自可公开使用的资料或本人可授权资料，不包含真实姓名、学号、身份证号、电话、住址、账号、二维码等隐私；含隐私时必须先脱敏。
3. 不要全部选择清晰扫描件，要同时包含清晰文档、复杂版面、表格、公式、图表、软件截图、场景文字、模糊/倾斜/阴影图片和完全无文字自然图像。
4. 至少50页组成“困难负样本组”：同一主题、相似标题、相似版式或同一文档相邻页，每组2至4页，用于检验模型是否真正理解内容。
5. 中文约60%，英文约25%，中英混合约15%；不要使用大量重复模板。
6. 图片短边建议不低于800像素；低清挑战样本除外，但要标注low_resolution、blur、skew、shadow或screen_photo。
7. PDF、DOCX、PPTX需要保留原文件，同时记录转换后的页码；不要只截取最容易识别的一页。
8. 每个单元生成字段：item_id、source_file、page_number、category、language、has_text、quality_tags、short_title、review_status、license_or_source。
9. 为每个单元编写1条自然语言检索问题，问题不能直接照抄文件名；其中至少30%的问题依赖视觉/版面信息，至少30%依赖文字语义，至少20%同时依赖文字和视觉。
10. 输出前检查：无重复文件、类别数量符合配比、隐私已处理、来源可说明、问题与目标页一一对应。
```

## 类别配比

| 类别 | 数量 | 重点 |
|---|---:|---|
| 清晰通用文档 | 30 | 通知、说明、报告、简历样例 |
| 复杂学术文档 | 30 | 双栏论文、教材、公式、图表 |
| 表格/表单/票据 | 30 | 成绩表、统计表、申请表、票据样例 |
| PPT/海报/课件 | 25 | 图文混排、流程图、课程幻灯片 |
| 软件/网页/代码截图 | 20 | IDE、仪表盘、网页、聊天界面 |
| 场景文字 | 25 | 标牌、横幅、书架、屏幕拍照 |
| 退化文档图像 | 20 | 模糊、倾斜、阴影、低清、折痕 |
| 无文字自然图像 | 20 | 人物、校园、风景、物体 |
| 合计 | 200 |  |

## 人工审核最低要求

- 每页名称、类别、是否含文字由本人确认。
- 每条查询目标由本人确认。
- 每个失败案例不得直接删除，标注为OCR错误、视觉歧义、版面歧义或标注问题。
- 正式评测前冻结测试集；不能看到结果后修改真值来提高指标。

## 推荐划分

- 开发集：120页，用于设计门控特征和调参。
- 验证集：40页，用于选择模型和阈值。
- 测试集：40页，只在最终方案确定后评测。

同一原始PDF、同一PPT或同一困难负样本组必须放在同一个划分中，避免相邻页泄漏。
