# Taxonomy v2：主类别与质量标签

## 标注原则

每张页面只选择一个主类别。主类别回答“这页内容是什么”，不能因为图片模糊、倾斜或反光而改变。

质量标签回答“这页拍得或扫得怎么样”，允许多选。“无明显质量问题”不能与其他问题同时选择。

## 7个主类别

| 主类别 | 判断标准 | 常见例子 |
|---|---|---|
| 普通文本型文档 | 以连续文字为主，没有更强的专业结构 | 通知、说明、报告、纪要、简历、书籍正文 |
| 学术/技术文档 | 包含论文结构、公式、实验图表或技术论述 | 论文、教材、实验报告、技术说明 |
| 证件/表格/表单/票据 | 依赖字段、单元格、键值关系或票据版式 | 身份证样例、成绩单、申请表、发票、参数表 |
| PPT/海报/课件 | 演示或宣传式图文排版 | 幻灯片、课程课件、宣传海报、信息图 |
| 软件/网页/代码 | 数字界面或程序内容 | 网页、软件界面、代码、终端、仪表盘、聊天页 |
| 场景文字 | 文字位于真实拍摄环境中 | 路牌、店招、横幅、公告栏、屏幕实拍 |
| 自然图像 | 主要信息来自人物、物体或自然场景 | 人物、建筑、车辆、动物、山水照片 |

## 11项质量标签

- 无明显质量问题
- 模糊
- 倾斜/透视
- 阴影
- 反光
- 低分辨率
- 遮挡
- 低对比度
- 扫描噪声/折痕
- 压缩失真
- 其他退化

## 容易混淆的例子

- 模糊成绩单：证件/表格/表单/票据 + 模糊
- 倾斜拍摄的论文：学术/技术文档 + 倾斜/透视
- 带反光的课程PPT照片：PPT/海报/课件 + 反光
- 清晰的软件截图：软件/网页/代码 + 无明显质量问题
- 没有文字的校园建筑照片：自然图像

原“清晰通用文档”已改为“普通文本型文档”，原“退化文档”已撤销。两者遗留页面都进入人工复核队列。

FUNSD、XFUND以及带`form_layout`、`real_form`等明确来源标签的页面可以预归为“证件/表格/表单/票据”，但自动建议不能替代人工确认。新闻、信件、简历、备忘录和邮件才归入“普通文本型文档”。
