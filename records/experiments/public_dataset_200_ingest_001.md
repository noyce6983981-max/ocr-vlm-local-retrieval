# 200 页公开候选集批量入库与冒烟验收 001

日期：2026-07-29

## 目标

验证 200 页候选集能否在单张 RTX 4060 Laptop GPU 上完成 OCR、文本索引、视觉索引和自然语言检索，并记录真实耗时与失败现象。

## 批量入库

- 输入：200 张 JPEG，96.62 MB。
- 新增页面：200。
- 重复页面：0。
- PaddleOCR：215.745 秒。
- OCR 语料构建：0.217 秒。
- BGE-M3 文本索引：18.899 秒。
- Qwen3-VL-Embedding-2B 视觉索引：50.960 秒。
- 端到端总耗时：291.037 秒。
- 生成的个人资料库：309.89 MB。
- 入库后 C 盘剩余空间：60.38 GB。

## 元数据与安全状态

- 8 个类别均按预设数量入库。
- 20 张无文字自然图像作为 OCR 困难负样本。
- 5 张公开样例需要隐私复核，不得直接作为 GitHub 展示图。
- 41 张需要类别复核。
- 原始图片位于 `data/incoming/`，由 Git 忽略。

## 冒烟检索 1：基金账户业务申请表

目标：`clear_document_001.jpg`

| 方法 | 目标排名 |
|---|---:|
| OCR 文本检索 | 1 |
| 视觉检索 | 5 |
| 固定融合 | 2 |
| OCR 质量自适应融合 | 2 |
| Qwen3-VL Top-10 重排 | 1 |

结论：第一阶段融合受到视觉相似基金表单干扰；重排器利用查询、图片和 OCR 内容的交叉匹配，将目标从第 2 名恢复到第 1 名。

## 冒烟检索 2：阳朔翠屏山水全景照片

目标：`natural_no_text_006.jpg`，OCR 平均置信度为 0。

| 方法 | 目标排名 |
|---|---:|
| OCR 文本检索 | 223 / 224 |
| 视觉检索 | 1 / 224 |
| 固定融合 | 202 / 224 |
| OCR 质量自适应融合 | 1 / 224 |

结论：目标没有 OCR 文本。固定融合被无效文本分数拖累，而质量门控自动采用视觉分支，恢复 Top-1。

## 结论边界

本记录只有 2 条定向查询，作用是验证端到端机制和发现困难负样本，不能写成正式 Recall@K 或泛化结论。正式结果必须等验证集、测试集查询真值完成后再计算。
