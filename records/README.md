# 项目过程记录

此目录用于保存项目中间的重要记录，并随代码提交到 GitHub。

## 目录说明

- `ENVIRONMENT.md`：电脑、Python、CUDA和依赖版本
- `COMMANDS.md`：确认运行成功的关键命令
- `CONTRIBUTION_LOG.md`：本人决策、亲手工作和对应证据
- `daily/`：每日完成内容、问题和下一步
- `experiments/`：实验配置、指标和结论
- `screenshots/`：无隐私的关键结果截图
- `private/`：私人临时记录，不会提交到 Git

## 记录原则

1. 只记录真实运行结果，不预填实验提升。
2. 每次实验记录配置、数据划分、随机种子和指标。
3. 不记录密码、Token、私人文档内容或绝对隐私路径。
4. 重要报错应记录“现象—原因—解决办法”。
5. 区分“工具自动完成”和“本人作出的技术判断”，突出真实贡献。
