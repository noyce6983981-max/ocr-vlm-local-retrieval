# BM25、三路RRF与查询感知混合召回消融

日期：2026-07-29

## 研究问题

在BGE-M3 OCR语义检索与Qwen3-VL图像检索之外加入BM25，是否能提升精确关键词查询？直接使用Dense、BM25、Image等权RRF是否可靠？

## 实现

- 对OCR文本块建立不依赖额外第三方包的BM25Okapi索引。
- 英文按词切分；中文同时保留单字和相邻二元词组。
- 1500页资料库对应4721个OCR文本块、62638个词项，索引构建0.290秒。
- 实时查询并行形成Dense、BM25和Image三个分支，保留标准RRF作为对照。
- 查询感知混合以OCR质量自适应Dense/Image为主，根据有效查询长度给BM25分配0.05、0.15或0.30的校准权重。
- 三路混合Top 10再交给Qwen3-VL-Reranker-2B重排。

## 24条人工真值结果

| 方法 | Recall@1 | Recall@3 | MRR |
|---|---:|---:|---:|
| Dense | 0.7083 | 0.7917 | 0.7564 |
| BM25 | 0.7500 | 0.7917 | 0.7841 |
| Image | 0.9167 | 0.9583 | 0.9435 |
| OCR质量自适应Dense/Image | 0.9583 | 0.9583 | 0.9643 |
| Dense + BM25 + Image等权RRF | 0.7500 | 0.7917 | 0.7908 |
| 候选级质量RRF初版 | 0.3750 | 0.6250 | 0.5287 |
| 查询感知三路混合 | 0.9583 | 1.0000 | 0.9722 |
| 三路混合 + Qwen3-VL重排 | 1.0000 | 1.0000 | 1.0000 |

三路混合重排的模型加载8.174秒、24条推理59.585秒，峰值保留显存4.609GiB。

## 关键发现

1. BM25单路优于Dense单路，但仍明显弱于视觉分支。
2. 等权RRF没有提升，原因是Dense和BM25都来自OCR文字，两个相关分支会重复投票并压过Image。
3. 候选级质量RRF初版进一步退化，已明确拒绝接入主流程。
4. 查询感知校准在不降低Recall@1的前提下，将Recall@3提高到1.0000、MRR提高到0.9722。
5. `q009`低清OCR页在三路混合中由原自适应融合第7名改善到第3名，重排后达到第1名。
6. 1500页“森林”实测中，短查询BM25权重自动降至0.05，Top结果保持为真实山林图片；等权RRF则会混入表格，验证了路由必要性。

## 结论边界

- 24条人工查询只能证明当前链路可行，不能作为1500页泛化结果。
- 查询长度权重仍是可解释启发式，后续需在更大的正式训练/验证/测试划分上固定参数。
- RRF负结果必须保留，不能只展示最终最优方法。
