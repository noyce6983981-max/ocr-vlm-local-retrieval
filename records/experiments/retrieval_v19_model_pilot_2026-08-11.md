# V19本地意图模型先导实验

## 结论先行

在72条开发者构造、尚未经人工复核的均衡先导查询上，Qwen3-1.7B具备继续开展V19的可行性；Qwen3-0.6B虽然能稳定输出JSON，但证据语义分类不足，不再作为主候选。加入不改变贪心输出的提示词查找解码后，B2混合路由通过路由增益、歧义子集增益、调用率、Schema稳定性和热P95时延门槛。下一步仍需人工复核先导标签和验证下游检索，不能直接进入正式留出评测或默认生产路径。

## 固定环境

- GPU：NVIDIA GeForce RTX 4060 Laptop GPU 8188 MiB
- 驱动：591.59
- Python：3.11.5
- PyTorch：2.7.1+cu128
- Transformers：5.14.1
- 推理模式：BF16/`torch_dtype=auto`，Qwen non-thinking，确定性生成
- 模型与提示词哈希：`data/evaluation/v19/model_pilot/model_manifest.json`

## 数据限制

- 72条查询六类各12条，全部标记为`draft_pilot_not_final`。
- 查询由开发阶段构造，标签未经过独立人工复核。
- 提示词边界在该先导集的分层小样上校准过，因此全部数字仅用于模型和工程方案选择，不能作为V19公开成绩。

## 模型选择

### Qwen3-0.6B

- 首轮72条B1：Accuracy 38.89%，Macro-F1 28.30%，非法JSON率0%。
- 调整证据边界和完整键名示例后，分层12条仍只有Accuracy 33.33%、Macro-F1 35.56%。
- 原生后端热P95约2.31秒，峰值显存约1.17 GiB。
- 结论：容量不足导致视觉、布局与实体证据语义不稳定；停止继续调提示词，避免在小先导集上过拟合。

### Qwen3-1.7B

- 分层12条：Accuracy 91.67%，Macro-F1 91.11%。
- 完整72条B1：Accuracy 69.44%，Macro-F1 68.69%，非法JSON率0%。
- B1各类召回：文字100%、视觉33.33%、布局33.33%、实体100%、主题91.67%、混合58.33%。
- 原生后端热P95约2.67秒，峰值显存约3.43 GiB。
- 结论：选为V19暂定模型；全量调用虽优于规则，但延迟和调用率不可接受，因此只用于混合路由。

## B2混合路由

门控只调用两类查询：旧规则返回`mixed`，或旧词法模块疑似漏掉自然人名精确查找。其余查询由规则直接处理。

| 指标 | B0规则 | B2混合 | 变化 |
| --- | ---: | ---: | ---: |
| Accuracy | 38.89% | 61.11% | +22.22pp |
| Macro-F1 | 38.57% | 58.22% | +19.65pp |
| 歧义调用子集Accuracy | 16.67% | 83.33% | +66.67pp |
| 歧义调用子集Macro-F1 | 6.35% | 63.89% | +57.54pp |
| LLM调用率 | 0% | 33.33% | +33.33pp |
| 非法JSON率 | — | 0% | 通过 |
| 回退率 | — | 0% | 通过 |
| 热P95路由时延 | 规则级 | 1.04秒 | 通过1.5秒门槛 |

B2在24个调用候选中修复18条、回退2条。两个回退均为规则原本正确的`mixed`查询被1.7B降为`text_evidence`，说明后续需要冻结保守采纳策略，而不是继续扩大调用范围。

## 决策

1. 暂定Qwen3-1.7B，淘汰0.6B主候选资格。
2. 保留B2为唯一正式候选，B1只作为诊断上限。
3. 在正式240条数据前，先人工复核先导标签并减少对正确`mixed`的覆盖；调用率不超过40%和热P95不超过1.5秒已在先导阶段满足。
4. 先导查询需要人工复核，但暂不要求用户审核240条正式集。
5. V18冻结成绩保持不变，V19当前不得发布为性能升级。

## 延迟优化负结果

使用Qwen3-0.6B为Qwen3-1.7B进行Transformers推测解码，在同一分层12条上的准确率保持91.67%，但P50由2.43秒升至2.85秒、P95由2.86秒升至4.08秒，峰值显存由3.43 GiB升至4.65 GiB。因此该路径被否决，相关实验接口未保留在主后端中。

随后采用无需第二模型的提示词查找解码，利用系统提示词中重复出现的完整JSON键进行候选复制。同一分层12条准确率仍为91.67%，P50由2.43秒降至1.05秒、P95由2.86秒降至1.07秒，峰值显存保持3.43 GiB。完整72条B2的P95为1.04秒，因此冻结`prompt_lookup_num_tokens=5`作为暂定推理参数。
