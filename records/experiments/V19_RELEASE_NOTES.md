# V19.0.0 — 必要条件证据优先检索

V19.0.0 将复合查询的完整必要条件覆盖加入实际检索界面，并保持普通查询对稳定
V18 链路的安全回退。

## 主要变化

- 新增“V19必要条件证据优先”检索模式；
- 显式多条件查询先在全库 OCR 中寻找同页完整证据，支持人工 OCR override；
- 无完整证据时保守拒答，避免单个高相似条件主导结果；
- 其他受支持契约使用 ColQwen2 多向量晚交互 Top-10 后核验；
- 未形成完整契约的查询自动回退 `quality_hybrid`，并记录介入与回退来源；
- 新增句式压力生成、条件聚合消融、完整证据提升和运行时测试；
- 保持本地运行，不增加商业模型 API 依赖。

## 验证摘要

- 来源隔离机器开发集：48/48 E2E，强负例 FAR 0；
- 两轮冻结后句式压力测试：各 48/48 E2E，强负例 FAR 0；
- 压力轮次原始 ColQwen2 正例 R@3 为 87.50% / 95.83%，证据优先后均为 100%；
- 全库显式证据烟雾测试：正例 0.625 秒、无答案拒答 0.612 秒。

上述结果均为机器构造、机器核验的开发或压力测试，不是新的真人独立留出结果。
V18 仍是最新独立真人评测；V19.0.0 是工程正式版，不改写历史研究结论。

## 容器边界

GHCR 镜像是无网络、CPU 可运行的最小复现演示，验证入库、检索、排序与拒答链路；
它不包含私有资料库、GPU 模型权重或 V19 开发产物，也不等同于复现完整 GPU 评测。
