# OCR-VLM 多模态检索 V2 最终实验记录

日期：2026-07-30

## 结论

已将原来的 OCR 文本、BM25、视觉三路融合升级为：

`BGE-M3 Dense + BM25 + Qwen3-VL Image + 真实元数据 + 查询路由 + Qwen3-VL Reranker`

V2 快速模式在验证集 17 条有答案查询上达到 Recall@1、Recall@3、MRR 均为 1.0000；V2 高精度模式进一步在 2 条无答案查询上全部正确拒答，验证集端到端 19/19。

## 关键改进

1. 真实元数据检索：索引公开原文件名、导入文件名、来源和来源标签，合成样本数为 0；解决无 OCR 自然图像无法按标题检索的问题。
2. 查询路由：文字证据查询优先 Dense + BM25，自然图像标题查询融合视觉与元数据，其余查询使用 OCR 质量自适应融合。
3. 多模态完整匹配核验：Qwen3-VL-Reranker 同时检查图片、OCR 和真实元数据；“局部视觉相似”不再视为充分匹配。
4. 拒答门控：精排阈值 0.646973，只用训练集标定；验证集 2/2 无答案正确拒绝。
5. 运行模式：网页保留快速模式，并默认选择高精度模式；相同查询继续使用缓存。

## 真实端到端验收

- 自然图像标题 `A Corner of Hongqiao Park`：由原第 572 名提升到 Top1。
